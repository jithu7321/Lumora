# Lumora
Lumora - focus timmer and productivity app
🚀 **Introducing Lumora — A Small Idea That Turned Into a Real Project**

Every project starts with an idea. But turning that idea into something that actually works is where the real learning begins.

I’m excited to share **Lumora — my focus and timer app**, a project I built with the goal of making it easier to manage time, stay focused, and build better study habits.

We all have days when we plan to complete several tasks, but staying focused and managing time consistently can be difficult. I wanted to explore how a simple timer application could help make the process more organized and encourage a more focused approach to everyday work and learning.

That thought became the starting point for Lumora. 💡

**✨ What is Lumora?**

Lumora is more than just a countdown timer. I designed it as a simple, organized space where users can manage their focus sessions and track their progress.

Some of the key features include:

⏱️ **Focus Timer:** Work in dedicated focus sessions and take breaks when needed.

🔄 **Pomodoro & Custom Timers:** Choose structured focus and break durations or customize them according to your needs.

📝 **Task Management:** Organize tasks and subjects to keep your work more structured.

📊 **History & Statistics:** Review completed sessions, monitor progress, and build consistency over time.

🎨 **Personalized Experience:** Switch between dark, light, and system themes according to your preference.

🔔 **Helpful Notifications:** Get notified when sessions end so you can stay on track.

📱 **Responsive Experience:** Use an interface designed to work across different screen sizes, with offline and installable-app support.

**🛠️ What building Lumora taught me**

One of the biggest lessons from this project is that developing an application involves much more than writing code.

A timer may sound like a simple feature, but making it reliable requires thinking about what happens when a user switches tabs, refreshes the page, changes settings, or returns to an ongoing session.

I learned the importance of handling these situations, managing application state, preserving user data, improving the user interface, and testing different scenarios instead of focusing only on the expected result.

I also explored features such as persistent storage, notifications, sound feedback, and converting the web experience into an Android application.

Every improvement taught me something new about the relationship between functionality, reliability, and user experience.

**💭 My biggest takeaway**

I’m realizing that a good application is not necessarily the one with the most features. It is the one that solves a real problem, feels intuitive to use, and works reliably when people need it.

Lumora has been a valuable learning experience for me—not just in development, but also in problem-solving, debugging, testing, and thinking from a user's perspective.

I see this project as a step forward in my development journey, and I’m excited to keep learning, improving, and building more meaningful applications.

This is just the beginning. 🚀
